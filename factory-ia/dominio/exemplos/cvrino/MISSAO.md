# Missão — CVRINO (exemplo)

**Nome:** CVRINO (cliente Gade Contabilidade)

**Uma frase:** painel web de contabilidade e ações fiscais para o escritório.

**Não é:** ERP genérico, app mobile, SaaS multi-tenant público.

**Usuários:** analista (`user`), administrador (`admin`), desenvolvedor (`dev`).

**Fora de escopo (agora):** filas, microsserviços, Node no servidor, Docker em produção.

**Critério de sucesso do produto:** rotinas fiscais e importações no prazo, sem
expor dado de cliente.
