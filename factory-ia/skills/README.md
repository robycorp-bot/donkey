# Skills

Skills de **processo** (como a fábrica opera) podem viver aqui.
Skills de **negócio** (como o produto funciona) vivem em `factory-ia/dominio/skills/`.

Não copie o texto de `AGENTS.md` para dentro de uma skill. A skill, se existir,
é um atalho que manda ler o canônico.

Adaptadores de ferramenta (`.claude/`, `.cursor/`) não são skills.
